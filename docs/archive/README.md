# Tài liệu lưu trữ

Thư mục này giữ các báo cáo và bộ tài liệu lịch sử đã được thay thế hoặc trùng lặp. Các file trong đây **không phải nguồn sự thật hiện tại** của hệ thống.

## Tài liệu hiện hành

Nguồn tài liệu kỹ thuật được duy trì tại thư mục [`docs/`](../):

- `REQUIREMENTS.md` — yêu cầu và quy trình nghiệp vụ
- `ARCHITECTURE.md` — kiến trúc hệ thống
- `DATABASE.md` — mô hình dữ liệu hiện tại
- `API.md` — API và schema
- `AI.md` — kiến trúc AI và fallback
- `SECURITY.md` — yêu cầu bảo mật
- `TESTING.md` — chiến lược kiểm thử
- `DEPLOYMENT.md` — triển khai
- `USER_GUIDE.md` — hướng dẫn sử dụng
- `SDLC_AI_USAGE.md` — ứng dụng AI trong SDLC
- `ui-design-system.md` — hệ thống thiết kế giao diện

Các tài liệu lưu trữ được giữ lại để tham khảo lịch sử và không nên dùng để xác nhận trạng thái hoặc hành vi hiện tại của mã nguồn.
